# 新人报销跑腿笔记（自包含版）

> 给第一次帮忙跑报销的同学。**看完这篇 + 跟着跑一次 = 会了。**
> 本笔记不依赖任何其他文件，遇到看不懂的词翻最后的「术语表」。

---

## 一、三句话版本

1. 报销 = 把**发票/票据**变成钱回到**项目经费卡**（不是打到个人钱包）
2. 全程一个系统：**高级财务管理平台**，网址 https://jhcwb.bit.edu.cn/
3. 必经三步：**网上预约报账 → 导师签字 → 投进报账投递机**，然后等打款

---

## 二、先分清是哪类报销

| 类别       | 什么时候用             | 需要什么                 | 一句话提醒                       |
| -------- | ----------------- | -------------------- | --------------------------- |
| **普通报销** | 买耗材、付版面费、专利费、市内打车 | 发票（+ 采购/验收材料）        | 公对公转账付的钱才能报                 |
| **差旅报销** | 出差产生的交通 + 住宿      | 行程单/车票 + 住宿发票 + 出差申请 | 住宿不能超标准                     |
| **酬金报销** | 给专家、学生、劳务人员发钱     | 发放表（**不需要发票**）       | 银行转账，标准是税后的（给专家发钱可以勾选税前/税后） |

### 普通报销细分

- **材料采购**：发票 + 采购申请单 + 验收单；单笔 ≥2 万必须签合同，≥20 万走比价/招标（买之前先问清楚门槛，别买完了发现要补合同）
- **版面费**：发票 + 录用通知
- **专利费**：发票 + 备案表（⚠️ 备案表要**完整签字**，专利老师发来的材料一份不落全交）
- **市内交通**：打车发票 + 交通明细表（注明**事由和起止路线**，没写会被退）

## 四、标准流程（照做就行）

### 第 1 步：收集票据
- 发票、行程单、车票，**原件**收好，拿到就**拍照留底**
- 抬头必须是「**北京理工大学**」，税号 **12100000400009127B**（开票前把这两个发给商家）
- 发票背面签经手人名字

### 第 2 步：网上预约报账
- 登录高级财务管理平台 → 网上预约报账 → 申请报销单
- 选对**费用项**、填对**经费卡号**（13 位项目代码，不确定就问导师或财务助理，选错会被退）
- ⚠️ 发票查验：**电子发票全部要查**、纸质发票 **≥1000 元**要查（系统里「增值税发票查验」功能）

### 第 3 步：打印报账单
- 系统生成的「北京理工大学网上报账单」打印出来

### 第 4 步：找导师签字
- 报账单 + 所有票据原件一起拿给导师
- ⚠️ 科研经费支出 = **经费负责人（导师）签字**；没签字的单子投了也白投

### 第 5 步：投递
- 装订好 → 投进自助报账投递机（中关村、良乡都有）

### 第 6 步：等打款
- 通常几天；被退单会有系统消息，留意查看

### 特殊流程：先打钱、后开发票（借款）

有些供应商要求**先付款、后开票**，不能走普通报销，要走**借款**：

1. 找供应商要**加盖公章的收费通知**（或报价单）
2. 在报销系统做**借款单**
3. 投递：**借款单 + 收费通知**
4. 收到发票后，在系统做**借款核销**（用发票冲销借款）

⚠️ 三条关键规则：
- **核销同账号**：借款从哪个经费卡出，核销就回到同一个账号，别串
- **个人垫付 → 转个人卡 + 附支付截图**：如果自己先垫了钱，打款时收款方式选个人卡，报销材料**必须附支付截图**
- **付给供应商 → 选「多种支付 - 公对公转账」**：系统里收款方选供应商时，支付方式选「多种支付」，走公对公转账

## 五、差旅报销专属要点

**材料**：出差申请表 + 报账单 + 机票行程单/火车票 + 住宿发票 + 会议通知（如参会）+ 导航截图和租车合同（如自驾）

**红线**：
1. 住宿、机票等**公对公转账**支付（或垫付后报销附支付截图）
2. 住宿**不超标准**：先问清楚经费是「竞争性」还是「非竞争性」，再查对应城市标准（常用城市见下表，单位：元/人·天）
3. 报了**出差补贴就不能报打车费**，二选一
4. 火车票按 **12306 实际支付金额**报，有优惠券按实付算，不按票面

## 六、酬金报销专属要点

**什么时候用**：给专家、学生、劳务人员发钱。**不需要发票**，用发放表。

### 酬金类型与标准（均为税后）

| 类型 | 标准 | 关键材料 |
|------|------|----------|
| 劳务费（学生/博士后/返聘/临时聘用） | 无统一标准，按约定 | 酬金申报单 |
| 专家评审、咨询费 | 见下表 | 申报单 + 发放表 + 会议通知（评审会时） |
| 讲座、报告费 | 院士 1500 / 正高 1000 / 副高及以下 500 元·学时 | 申报单 + 发放表 |
| 公共服务酬金（答辩/监考/考务） | 答辩：硕士 2000/生、博士 4000/生 | 申报单 + 发放表 + 答辩名单 |
| 课时费 | 各单位自定 | 酬金申报单 |

### 专家评审、咨询费标准表（元）

| 形式 | 院士/全国知名专家 | 高级职称 | 其他专业人员 |
|------|:---:|:---:|:---:|
| 会议评审·半天 | 1350—2160/人 | 900—1440/人 | 540—900/人 |
| 会议评审·第1-2天 | 2250—3600/人·天 | 1500—2400/人·天 | 900—1500/人·天 |
| 会议评审·第3天起 | 1125—1800/人·天 | 750—1200/人·天 | 450—750/人·天 |
| 通讯评议 | 300—1200/人·次 | 300—1200/人·次 | 180—750/人·次 |

### 酬金规则

- 原则上**银行转账**到专家本人账户（现金仅限会议通知明确要求时）
- 线上会议/通讯评议：专家签字栏可不填
- 校内人员：只填工作单位，发放**税前金额**
- 发放表下载：计划财务部网站 → 下载中心 → 会计核算中心 → 酬金类表格
- ⚠️ 不能发放给参与项目研究及其管理的人员

## 七、提交前完整检查清单（逐项打勾）

### 付款方式
- [ ] 公对公转账支付？（私人付的钱报不了）
- [ ] 个人垫付报销（转个人卡）→ 已附**支付截图**？

### 发票
- [ ] 抬头：北京理工大学；税号：12100000400009127B
- [ ] 纸质票据要**原件**（复印件、照片打印件无效）
- [ ] 电子票据全部查验 + 纸质 ≥1000 元查验
- [ ] 发票背面签名
- [ ] 发票金额与报销单一致

### 系统填报
- [ ] 费用项选对、经费卡号（13 位）填对、预算科目正确
- [ ] 报账单已打印

### 附件材料
- [ ] 会议通知/邀请函（会议费）、行程单（差旅）、采购申请单+验收单（采购）、合同（≥2 万）、备案表（专利费）
- [ ] 材料按顺序整理好

### 签字
- [ ] 经费负责人（导师）已签字 + 经手人已签字 + 验收人已签字（采购类）

### 投递前
- [ ] 纸质材料齐全 + 手机里有电子版备份
- [ ] 知道最近投递机位置（中关村/良乡）

## 八、票据丢了怎么办

1. 找开票单位要**记账联复印件 + 加盖发票专用章**
2. 填「报销票据丢失情况说明」，找核算室负责人审批
3. 火车票/机票丢了：提供网上订单 + 付款截图
> ⚠️ 所以拿到票据**立刻拍照**，丢不了。

## 十一、采购金额门槛（买东西前先看）

| 金额 | 规则 |
|------|------|
| < 2 万 | 自行采购，**不用签合同**（测试/服务费直接凭收费通知+发票报销） |
| ≥ 2 万 | **必须签合同** |
| 20—50 万（科研仪器） | 自行比价采购（3 家报价 + 比价小组） |
| ≥ 50 万（科研仪器）/ ≥ 20 万（目录外） | 招采中心组织（公开招标/校级评比） |

### 需要签合同的采购全流程（照做）

1. 财务主页（https://jhcwb.bit.edu.cn/）→ 选**采购管理系统** → 提交**采购申请**
2. 申请审批通过后 → 提交**采购合同申请**（上传合同）
3. **盖章**
4. **借款**（需要先打款时：借款单 + 加盖公章的收费通知，投递）
5. 供应商**开发票**
6. **核销**（发票冲销借款，同一经费账号）

> 关键点：采购申请 → 合同申请 → 盖章 → 借款 → 开发票 → 核销，链条别跳步，前一步没批完走不了下一步。

> ⚠️ **设备类采购多一步**：仪器、家具等到货验收后，先在「北京理工大学设备家具管理平台」做**资产转固**，拿到资产编号后财务才能报销/核销。入口：http://10.0.8.170:8080/netcx/loginUser.do（经统一身份认证登录，⚠️ 内网系统，需校内网或 VPN）。

> ⚠️ **危险化学品例外**：不走普通采购渠道，必须在「计划财务部 - 化学品采购平台」采购。

## 十二、术语表

| 词 | 意思 |
|----|------|
| 报账单 | 系统生成的报销单据，打印 + 签字 + 投递 |
| 投递机 | 收报账单的自助机器（不用排队找窗口） |
| 经费卡 | 项目的钱袋子编号（13 位），报销的钱从这里面出 |
| 酬金 | 发给个人的钱（专家费、劳务费），不走发票走发放表 |
| 上账 | 外部打来的经费划入项目经费卡 |
| 发票查验 | 在税务系统验证发票真伪，防假票 |
| 竞争性经费 | 从校外竞争获得的科研经费（国自然、重点研发等），标准更高 |
| 非竞争性经费 | 校内/财政拨款经费，标准按国家统一口径 |

## 十三、常见 Q&A

**Q：投递完多久到账？**
A：一般几天。退单会有系统消息，别投完就不管了。

**Q：月底去办有什么坑？**
A：每月 25 日 17:00 后财务封账，月底赶事要提前。

**Q：费用项选错了怎么办？**
A：会被退单，改过来重新投。不确定就先问导师或财务助理，别猜。

**Q：帮别人跑，报账单谁签字？**
A：**经费负责人**（一般是导师）签字，谁出钱谁签字。

**Q：买了东西发现超 2 万没签合同怎么办？**
A：补签合同再报销；金额压不住就拆单会被查，别拆。

**Q：出差补贴和打车费到底怎么选？**
A：算一下哪个划算。要打车发票报销就别领补贴；要领补贴就别报打车。
