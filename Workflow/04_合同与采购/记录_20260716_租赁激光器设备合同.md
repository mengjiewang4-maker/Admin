## 3. 采购方式判断

| 条件 | 判断 |
|------|:---:|
| 金额 ≤ 20 万元 | ✅ 自行采购 |
| 单次 ≥ 2 万元 | ✅ 必须签合同 |
| 系统 | **采购管理系统**（非科研管理服务平台） |

---

## 4. 合同文本

使用学校官方模板：**《北京理工大学货物类采购合同（示范文本）》**
下载地址：计划财务部网站 → 下载中心

在模板基础上补充：
- [ ] 激光器型号、技术参数、数量
- [ ] 租赁起止日期
- [ ] 租金总额与支付方式
- [ ] 设备交付、验收、归还条款
- [ ] 使用期间维护与损坏责任
