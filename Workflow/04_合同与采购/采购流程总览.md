# 采购流程总览

> 买东西、签合同，先看这里。核心口诀：**先判断金额 → 再决定要不要签合同 → 走对应流程**。

---

## 1. 采购金额分级速查

| 金额 | 采购方式 | 要签合同？ |
|------|----------|:---:|
| **< 2 万** | 自行采购 | ❌ 凭发票报销；测试/服务费凭「收费通知 + 发票」公对公转账即可 |
| **≥ 2 万** | 自行采购 | ✅ **必须签合同** |
| **20—50 万**（科研仪器设备） | **自行比价采购** | ✅（3 家报价 + 比价报告） |
| **≥ 50 万**（科研仪器）/ **≥ 20 万**（集采目录外） | **招采中心组织**（公开招标/校级评比） | ✅ 流程长，提前规划 |
| 集采目录内货物 | 政府集中采购（电子卖场） | ✅ 采购合同 + 电子验收单 |

> ⚠️ 其他必须签合同的情形：分期付款、涉密科技合同（用审批表代替）、外协/外拨。
> 
> ⚠️ **危险化学品例外**：不走普通采购渠道，必须在「北京理工大学计划财务部 - **化学品采购平台**」采购。

---

## 2. 系统入口（先分清「付钱」还是「进款」）

| 场景 | 系统 | 入口 |
|------|------|------|
| **采购合同（我们付钱）** | **采购管理系统** | 财务主页 https://jhcwb.bit.edu.cn/ 选择进入 |
| **项目合同（进款）** | **科研管理服务平台** | https://kyxt.bit.edu.cn/ |

> 一句话：**付款合同走采购管理系统，进款合同走科研管理服务平台**，走错系统白忙。

---

## 3. 签合同采购全流程（标准链路）

```
① 采购管理系统 → 提交采购申请
② 审批通过 → 提交采购合同申请（上传合同）
③ 盖章（系统生成用印编号 → 师生服务大厅盖章）
④ 借款（先款后票时：借款单 + 加盖公章的收费通知 → 投递）
⑤ 供应商开发票
⑥ 核销（发票冲销借款，同一经费账号）
```

⚠️ 三条关键规则：
- 链条**别跳步**，前一步没批完走不了下一步
- **借款核销同账号**：借款从哪个经费卡出，核销回同一个账号
- 付供应商时系统选**「多种支付 - 公对公转账」**；个人垫付则转个人卡

### 设备采购专属：资产转固

设备类采购（仪器、家具等）到货**验收完成后**，还要在「**北京理工大学设备家具管理平台**」办理**资产转固**登记：

- **入口**：http://10.0.8.170:8080/netcx/loginUser.do （经 sso.bit.edu.cn 统一身份认证登录）
- ⚠️ **内网系统**：需校内网或 VPN 才能访问
- **时机**：验收完成 → 财务报销/核销**之前**
- **原因**：转固后拿到资产编号，财务才能入账
- ⚠️ 忘了转固，报销会被退单

## 4. 比价采购流程（20—50 万元科研仪器设备）

1. **建比价小组**：3 人（采购人 + ≥2 名中级及以上职称专家）
2. **获取报价**：选 3 家以上供应商，拿**加盖公章**的报价单
3. **比价**：选满足要求且报价最低的，出具《科研仪器设备比价采购报告》
4. **系统操作**：采购管理系统 → 提交采购申请 → 选「比价」→ 上传比价报告 + 3 家报价单
5. **合同签署**：审批通过后签合同（参考《货物类采购合同示范文本》，计划财务部网站下载中心下载）
6. **合同盖章**：系统提交合同申请 → 盖章

## 5. 合同盖章流程

### 🟢 非涉密采购合同：走线上

```
采购管理系统提交合同用印申请 → 上传合同扫描件 + 采购申请审批单（如需）
    → 学院线上审核 → 生成用印编号 → 凭编号去师生服务大厅盖章
```

### 🔴 涉密采购合同：走线下

```
打印合同 + 进款/出款审批表 → 学院科研干事 → 学院领导审核
    → 逸夫楼科研院复核 → 生成用印编号 → 师生服务大厅盖章
```

**我方印章**：北京理工大学公章 / 科技合同专用章 / 合同专用章（依合同类型）

## 6. 合同原件 vs 复印件（报销/核销时交哪个）

| 付款方式 | 借款时 | 核销/报销时 |
|----------|:---:|:---:|
| 先借款再核销 | 复印件 | **原件** |
| 直接报销（不借款） | — | **原件** |
| 分期付款 | 复印件（每次） | **原件**（最后一次） |

---

## 7. 合同盖章后归档

| 项目类型 | 归档要求 |
|----------|----------|
| 横向项目 | 合同原件 1 份 + 备案表 → 逸夫楼 101 董怡 |
| GF / 纵向项目 | 合同原件 1 份 → 项目主管（⚠️ **归档后才能办出款**） |
| 一般采购 | 合同 + 发票一起报销 |

---

## 8. 常见错误 ⚠️

| # | 错误 | 预防 |
|---|------|------|
| 1 | 没签合同就买了（≥2 万） | 采购前先查第一节金额分级 |
| 2 | 付款合同走了科研管理服务平台 | 付钱走采购管理系统，进款走 kyxt |
| 3 | 合同没归档就办出款 | GF/纵向项目归档是出款前置条件 |
| 4 | 合同金额与发票不一致 | 签合同前确认金额 |
| 5 | 涉密合同走了线上 | 涉密一律走线下纸质 |
| 6 | 借款核销用了不同经费卡 | 借款与核销同一账号 |
| 7 | 比价没留 3 家报价单 | 20-50 万科研仪器必须留档报价单 |
