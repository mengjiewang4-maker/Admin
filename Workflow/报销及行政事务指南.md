# 报销及行政事务指南

> 一页速查。报销分三类，盖章走一条线。
> 详细流程点链接；办具体事之前先看检查清单。

---

## 一、报销

### 三大类速查

| 大类 | 包含什么 | 入口 | 关键点 |
|------|----------|------|--------|
| **普通报销** | 材料采购、版面费、专利费、日常交通、会议注册费 | [[01_报销/报销流程总览\|报销流程总览]] | 公对公支付、发票查验 |
| **差旅报销** | 出差交通 + 住宿 + 补助 | [[01_报销/差旅报销\|差旅报销]] | 住宿不超城市标准；补助与打车费互斥 |
| **酬金报销** | 劳务费、专家评审费、讲座报告费、答辩/监考费等 | [[01_报销/酬金报销\|酬金报销]] | 不发发票走发放表；税后标准；银行转账 |

### 通用流程（所有报销同款）

```
收集票据 → 高级财务管理平台预约报账 → 打印报账单
    → 导师（经费负责人）签字 → 投递自助报账投递机 → 等打款
```

🔗 系统：https://jhcwb.bit.edu.cn/（网上预约报账 → 申请报销单）

### 特殊流程：先打钱、后开发票（借款）

> [!note] 借款流程
> 供应商要求先款后票时：拿**加盖公章的收费通知/报价单** → 报销系统做**借款单** → 投递（借款单 + 收费通知）→ 收到发票后做**借款核销**。
> ⚠️ 核销用**同一个经费账号**；个人垫付转**个人卡**（⚠️ 附支付截图）；付供应商选**「多种支付 - 公对公转账」**。

### 报销前 3 问

1. 经费余额够吗？（问导师或查系统）
2. 预算科目允许吗？（走错科目必退）
3. [[01_报销/清单_报销提交前\|提交前检查清单]] 过一遍了吗？

### 三类各自的底线规则

> [!warning] 普通报销
> - 因公支出**一律公对公转账**（暂未办公务卡），垫付报销必须附支付截图
> - 电子发票全查 + 纸质 ≥1000 元必查（增值税发票查验）
> - 单次 ≥2 万元采购必须签合同，流程：财务主页 → **采购管理系统** → 采购申请 → 合同申请 → 盖章 → 借款 → 开发票 → 核销（借款核销同一经费账号）

> [!warning] 差旅报销
> - 住宿、机票走公对公转账（或垫付附截图）
> - 住宿按「竞争性/非竞争性」分表执行城市标准（先确认经费类型）
> - 报了出差补贴就不能报打车费，二选一
> - 火车票按 **12306 实付金额**报，不按票面

> [!warning] 酬金报销
> - 不需要发票 → 用「发放表」+「酬金申报单」
> - 标准全部**税后**：讲座费 1500/1000/500 元·学时；评审费半天 60%、第 3 天起 50%
> - 原则上银行转账到专家本人卡；线上形式专家可不签字
> - 会议费、差旅费、酬金**三张单分开走**，不混报

## 二、盖章申请

### 主场景：项目申请 → 进款审批盖章

> 你 90% 的盖章需求来自这里：项目申报材料需要盖章时，走「进款审批」流程。

```
① 系统填报 → ② 学院审核（定密 + 材料）→ ③ 科研院审核
    → ④ 生成用印编号 → ⑤ 教师服务大厅盖章
```

**材料**：进款审批表（系统打印）+ 申报材料
**系统**：专用项目管理系统（横向/涉密类）；主管见 [[03_项目申请/项目申请总览\|项目申请总览]]

### 其他盖章场景

| 场景 | 流程页 | 关键点 |
|------|--------|--------|
| 报销单 / 证明盖章 | [[02_盖章/学院公章\|学院公章]] | 导师先签字 |
| 采购合同章 | [[02_盖章/采购合同公章\|采购合同公章]] | 采购管理系统先过审批 |
| 学校公章 | [[02_盖章/学校公章\|学校公章]] | 学院先审 |

### 盖章前 4 查

1. 导师签字了吗？（绝大多数章的先决条件）
2. 系统审批过了吗？（没通过不给你盖）
3. 备份带了吗？（至少多带 1-2 份）
4. 时间地点对吗？（别卡下班前 10 分钟、中午休息）

> 完整检查项 → [[02_盖章/清单_盖章提交前\|盖章前检查清单]]

### 盖章通用原则

- 📄 多带备份，盖坏了还有
- ✍️ 导师先签，学院再审，最后才盖
- 📋 该走的系统审批先走完，盖章只是最后一环
- 🕐 上午去比下午稳
