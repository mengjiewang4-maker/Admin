# 办学术会议准备清单

> 办会前逐项打勾。报销科目按 BIT 财务报销指南第 4.1 节（PDF 第 82—85 页）规则映射。

---

## 一、物料清单（含报销科目）

### 📦 会议资料类

- [ ] **会议手册** → 印刷费 ✅
  - 内容：日程表、报告摘要、报告人简介、校园/会场地图、赞助页
  - 数量：参会人数 + 20% 余量
  - 印刷周期：提前 **7 天**送印（高峰期更早）
- [ ] **手提袋**（会议资料袋）→ 办公用品费 ✅
  - 装手册 + 本 + 笔；印会议名称即可
- [ ] **笔记本 + 签字笔** → 办公用品费 ⚠️ 见第二节红线（笔记本注意「纪念」字样）
  - 签字笔：建议 2 支/人（签到 1 支 + 资料袋 1 支），嘉宾席另备好笔
- [ ] **文件袋** → 办公用品费 ✅
  - 用途：装日程表/报告论文等散件资料，放入手提袋内；按人数 + 10% 备
- [ ] **PPT 封面模板** → 自行设计免费 / 或走宣传费 ✅
  - 规格：16:9；首页 = 会议全称 + 主办单位 + 时间地点；报告人页 = 姓名 + 单位 + 报告题目
  - 提前 **5 天**发给所有报告人，统一收齐 → 拷入会场电脑 → 提前彩排测试

### ☕ 会场保障类

- [ ] **茶歇** → 伙食费 ✅（计入 150 元/人·天 定额内）
  - 上午、下午各一次；品类：咖啡/茶 + 点心 + 水果
  - 按人数提前 2 天预订，比实际人数少备 10%（常有缺席）
- [ ] **矿泉水** → 办公用品费 ✅
  - 每人每天 1—2 瓶；会议室后排 + 嘉宾席 + 报告台各备一箱

### 🏟 会场布置类（最容易漏的）

- [ ] 横幅 / 易拉宝 → 宣传费
- [ ] 席卡、桌签 → 办公用品费
- [ ] 代表证 / 工作证 → 印刷费
- [ ] **会议签到表**（必须用 BIT 官方表）→ 报销必需材料
- [ ] 摄影 / 直播设备（混合会议时）
- [ ] 线上会议系统 + 链接测试（如设线上分会场）

## 二、⚠️ 合规红线

> [!warning] 纪念笔记本 = 纪念品风险
> 会议费报销范围**不含纪念品、礼品**。「纪念笔记本」可能被认定为纪念品而退单。
> **安全做法**：定位为「会议记录本」随资料袋发放；发票开「办公用品」；预算从「其他费用」定额（100 元/人·天）内出；物料上不印「纪念」字样。

> [!warning] 综合定额 750 元/人·天是总天花板
> 业务会议：住宿 500 + 伙食 150 + 其他 100 = **750 元/人·天**
> - 茶歇计入**伙食费**；手册、袋子、文件袋、签字笔、水、笔记本计入**其他费用**（场地租赁、办公用品、印刷、宣传、交通）
> - 各项之间**可调剂**，但未实际发生的项目不得参与调剂
> - 总控公式：`物料总花费 ≤ 750 × 人数 × 天数`

> [!warning] 专家酬金不在 750 定额内
> 专家讲座报告费 / 评审咨询费、受邀代表旅费是**综合定额外**单独申报的科目，审批表里要和会务费**分行列出**（别混进会议费）。

## 三、办会手续清单（BIT）

- [ ] **会前**：北京理工大学科研会议审批表（科研经费办会必填，科研院审批）
- [ ] **会中**：会议签到表（官方表）
- [ ] **会后报销**：网上报账单 + 发票 + 明细（会议费发票 ≥1 万元需明细）+ 合同原件（金额 ≥2 万元）
- [ ] **专家酬金**：酬金申报单 + 业务酬金（讲座、报告费 / 专家评审、咨询费）发放表
- [ ] **受邀代表旅费**：走差旅费（凭票实报，住宿按城市标准）

## 四、时间线

| 时间 | 事项 |
|------|------|
| 会前 4 周 | 审批表提交、预算核定、场地预订 |
| 会前 2 周 | 手册内容定稿、物料（袋/本/笔/水）下单 |
| 会前 1 周 | 手册送印、茶歇预订、PPT 模板收齐 |
| 会前 1 天 | 物料清点、会场布置、设备彩排、签到表打印 |
| 会后 1 周 | 收发票 → 报销 + 专家酬金发放 |
